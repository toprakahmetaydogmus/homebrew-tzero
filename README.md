# Homebrew Tap for T-Zero

Official Homebrew Tap for **T-Zero**: Deterministic AST Context Compressor, 95% Token Reducer & 20-Tool MCP Server for AI Coding Assistants (Claude Desktop, Cursor, Windsurf, Copilot).

- **Main Repository:** [https://github.com/toprakahmetaydogmus/TZeroAlgorithm](https://github.com/toprakahmetaydogmus/TZeroAlgorithm)
- **Author:** Toprak Ahmet Aydoğmuş (15-Year-Old Solo Developer @ Siber Akademi)

## Installation

```bash
brew tap toprakahmetaydogmus/tzero
brew install tzero
```

## Quickstart

```bash
# 1-Click initialize Cursor, Claude Desktop, Windsurf, VS Code:
tzero init

# Pre-flight AI hallucination lock:
tzero --guard <file_or_code>

# 1-Click Auto-Vault secret migration:
tzero --vault --migrate

# Autonomous PC & codebase doctor:
tzero pc-fixer
```
